# Ultron
Hands-free voice assistant for Android: wake word, 3D orb, phone control, database, GitHub builder, Kali and QEMU via Termux.
Push to GitHub and the Actions workflow builds `app-debug.apk` (Actions tab > latest run > Artifacts).
After installing: grant mic, enable Ultron under Accessibility, add an API key in Settings, say "Ultron".
For Termux features: install Termux from F-Droid, add `allow-external-apps=true` to `~/.termux/termux.properties`, restart Termux.
